Política de Privacidade

Como tratamos os dados informados no formulário de contato deste site.

Aviso: este texto é informativo e não substitui parecer jurídico. Recomenda-se a revisão por profissional habilitado antes da publicação do site.

1. Quem somos

Este site pertence à Opportunity Engenharia e Segurança do Trabalho, que atende empresas em Mogi das Cruzes e região. Na Lei Geral de Proteção de Dados (LGPD), a Opportunity é a responsável pelas decisões sobre o uso dos dados descritos abaixo.

2. Quais dados são coletados

O formulário de contato solicita:

  • nome;
  • empresa (opcional);
  • número de WhatsApp;
  • serviço de interesse;
  • mensagem (opcional).

Informe apenas o que for necessário para o contato. Evite incluir dados sensíveis ou documentos pessoais na mensagem.

3. Para que usamos os dados

Os dados são usados para responder ao seu contato, entender sua necessidade e, quando for o caso, enviar informações ou uma proposta sobre os serviços da Opportunity.

4. Como o envio acontece

Este é um site estático, sem servidor próprio ou banco de dados. Ao clicar em “Enviar pelo WhatsApp”, o site monta uma mensagem com os dados que você preencheu e abre o WhatsApp para você revisar e enviar. Os dados não são armazenados por este site.

Depois que a mensagem é enviada, o tratamento passa a ocorrer no WhatsApp, que tem seus próprios termos e política de privacidade. Recomendamos consultá-los.

5. Autorização

O formulário só pode ser enviado se você marcar a caixa de autorização para contato. Você pode deixar de usar o formulário a qualquer momento ou entrar em contato diretamente pelos canais informados no site.

6. Compartilhamento

Os dados não devem ser compartilhados com terceiros sem necessidade. O compartilhamento só deve ocorrer quando for indispensável para atender sua solicitação ou quando houver obrigação legal.

7. Cookies, análise de acessos e rastreadores

Esta versão do site não utiliza cookies de publicidade, Google Analytics, pixels de rastreamento nem outras ferramentas de monitoramento. Se alguma for adicionada no futuro, esta política deve ser atualizada. O site também não carrega fontes ou scripts de terceiros.

Os links para o WhatsApp levam a um serviço externo, e a hospedagem do site (por exemplo, GitHub Pages) pode registrar dados técnicos de acesso, como endereço IP, conforme a política do provedor.

8. Seus direitos

Nos termos da LGPD, você pode solicitar, entre outras possibilidades, a confirmação de que tratamos dados seus, o acesso a esses dados, a correção de informações, a eliminação de dados quando cabível e informações sobre o compartilhamento.

10. Atualizações

Esta política pode ser atualizada para refletir mudanças no site ou na legislação. Consulte esta página periodicamente.
